RowHammer Fault Injection on High Bandwidth Memory

Graduate Research Assistant · UCF Hardware Security · 2024–2026

RowHammer flips bits in DRAM by repeatedly activating adjacent rows. This work asked whether the same class of fault injection carries over to High Bandwidth Memory, which stacks and organizes DRAM differently.

  • Implemented custom memory access engines in SystemVerilog on a Xilinx Alveo U280 FPGA, targeting the on-package HBM stacks.
  • Characterized bit-flip behavior across DRAM access patterns and presented findings to faculty and peer researchers.
